## What this is

The AI thinking tools and agent utilities I use for hard decisions, games, and giving agents new powers. No code copied here, only links to the originals plus notes.

## What's inside

| Tool | What it does | Link | License | My note |
|------|--------------|------|---------|---------|
| council | Council of High Intelligence: multi-persona deliberation | bundled with my agent environment | check upstream | For decisions I should not make alone. It argues before agreeing, which is the point. |
| game-studios | Claude-Code-Game-Studios: 49 roles and 74 skills for web games | bundled with my agent environment | check upstream | My stack for building web games. Run it lean. |
| api-anything | Turns websites into callable read-operations for agents | [goodnight000/api-anything](https://github.com/goodnight000/api-anything) | check upstream | Give an agent a website as an API. I use it for watchers and research reads. |
| deepseek-harness | DeepSeek agent harness and plugins | [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) | check upstream | For running and extending the DeepSeek agent setup. |

## How I use these

Big call to make: council first, then decide. Game idea: game-studios. Need an agent to read the same site every day: api-anything. Everything else is situational.

## How to use this list

Pick the tool that matches your problem, follow its link, install it per its own README. Star the ones you keep coming back to.
